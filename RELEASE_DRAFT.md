# Newgrounds Rumble Android v0.1.3

The first public Android build of Newgrounds Rumble, powered by Ruffle and FrostFrontend.

- Gamepad support with remappable actions.
- Touch joystick or D-pad, with Up to jump and Light, Heavy and Block buttons.
- Original aspect ratio or stretch-to-screen display.
- Sound settings and a left/right speaker test.
- Game progress and settings saved between launches.
- Update checks in FrostFrontend, with optional checks at startup.
- Pico and Hank launcher artwork.

Requires Android 8.0 or newer. Install the APK, open it and import your original Newgrounds Rumble SWF. The game file is not included.

Tested on the AYN Odin 2 Portal. Performance and compatibility on other devices have not yet been verified.

Original game by NegativeONE, Luis and MindChamber. Android adaptation by Frostie77. Built with Ruffle and FrostFrontend.
